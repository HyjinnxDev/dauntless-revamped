# Hunt Pass wiki audit

Researched 12 October 2026. Opened [Hunt Pass](https://dauntless.fandom.com/wiki/Hunt_Pass#Rewards), all four lists, and every linked pass page in browser. Direct HTTP/web fetch was blocked; rendered browser pages supplied complete reward tables. **64 pass pages, 2,665 numeric tier rows**: 28 classic/mini, 22 cosmetic, 5 Slayer Commission, 9 event. This is research inventory, not an imported runtime catalog or verified client-asset manifest.

Historical platinum columns are separate Basic and Elite rewards, not purchase prices. For single-track passes, payout is zero. Values below derive from numeric platinum entries in rendered tables; page prose and live game versions can differ. Main page's 950 refund is combined 200 Basic + 750 Elite for later passes, not 950 on Elite alone. Keep sources when resolving differences.
